# Checklist UAT

- [ ] Admin dan Analis dapat login.
- [ ] Analis dapat input Project, Part, COA Part, batch number, dan PDF.
- [ ] File selain PDF atau lebih dari 10 MB ditolak.
- [ ] Kombinasi Part, COA Part, dan batch number yang sama ditolak.
- [ ] Dokumen dapat dicari berdasarkan Project, COA, batch, dan Part.
- [ ] Dokumen PDF dapat diunduh oleh pengguna yang login.
- [ ] Dashboard menghitung total dokumen, Part A, dan Part B dengan benar.
- [ ] Grafik garis Dashboard sesuai periode yang dipilih.
- [ ] Modal input dapat digunakan pada desktop dan ponsel.
